# Cod

Cod is a desktop workspace for agent-driven development. You run several workspaces side by side, and each one holds its repos (as git worktrees), its Claude Code and Codex sessions in a real chat UI instead of a terminal, a code view with a review mode, and web pages such as an issue tracker, a wiki or GitLab as panes. You always see which workspace needs you, and agents can drive the app: open files, diffs and pages, and ask you for a review.

It is minimal and opinionated, and it aims to feel like Zed: fast, quiet, keyboard first, few settings. It is an Electron app, Linux first and macOS second.

## Status

Early, pre-alpha. There is no usable app yet.

Cod is a personal tool developed in the open. A human stakeholder sets priorities and accepts the work; a team of AI agents writes the stories, the tests and the code, and reviews it. The process lives in [AGENTS.md](AGENTS.md), and the backlog lives in GitHub Issues.
